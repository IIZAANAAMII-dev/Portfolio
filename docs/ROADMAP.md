# Roadmap

Une phase n'est jamais commencée si la précédente n'est pas stable
(`npm run build` vert + vérification visuelle + commit).

## Phase 0 — Planification ✅
Docs `ARCHITECTURE`, `DESIGN`, `ROADMAP`, `ASSETS`, `BLENDER`.

## Phase 1 — Foundation ✅
Next.js 16 + TS + Tailwind v4 + R3F + drei. Canvas, caméra, lumières, store, détection
WebGL, structure de dossiers, fonts.

## Phase 2 — Intro ✅
Île de départ, ponton, bateau placeholder, brouillard dense, « Click to start »,
world reveal orchestré (GSAP), loader premium.

## Phase 3 — Océan & bateau ✅
Océan shader, clic sur l'eau, rotation progressive, trajectoire lissée, sillage,
caméra qui suit.

## Phase 4 — Archipel ✅
6 îles data-driven avec identité visuelle, docks, hover, labels.

## Phase 5 — Interactions ✅
Focus caméra, panneaux, nav discrète, deep linking, fermeture.

## Phase 6 — Contenu ⏳
Remplacer les données provisoires par les vrais projets / expériences / parcours.
**Bloqué : nécessite les informations réelles de Kyliann.**

## Phase 7 — UX premium ⏳
Sound design complet, micro-interactions, transitions de panneau affinées,
Quick View enrichie.

## Phase 8 — Optimisation
Budget : 60 fps desktop, < 2.5 s TTI, < 5 Mo d'assets initiaux.
Mesures : draw calls, mémoire GPU, taille du bundle.

## Phase 9 — Mobile
Caméra plus haute, panneaux plein écran, densité de végétation réduite, DPR 1.5,
ombres désactivées.

## Phase 10 — Polish
Oiseaux, particules, easter eggs (3 à 5), détails d'environnement, README + captures.
